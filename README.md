# iM 파트너

대구 전통시장·골목상권 소상공인을 위한 AI 기반 경영·금융 도우미 프로토타입입니다.

## 1. 프로젝트 개요

소상공인은 매출이 변한 원인과 현재 자금 상태를 한눈에 파악하기 어렵습니다. iM 파트너는 카드소비, 유동인구, 매출·지출, 정책·지원사업 등의 데이터를 연결해 매출 변화의 원인 후보를 설명하고 운영·금융 관련 인사이트와 회복 플랜을 제공하는 서비스를 목표로 합니다.

## 2. 주요 사용자 흐름

```text
이소현의 가게 선택
    ↓
매출 감소 현황 확인
    ↓
카드소비·유동인구 비교
    ↓
매출 감소 요인 후보와 시간대별 인사이트 확인
    ↓
골목상권 회복 플랜 확인
    ↓
AI 리포트와 대응 방법 확인
    ↓
AI 비서에게 추가 질문
```

## 3. 핵심 기능

- 상권 데이터 기반 인사이트 제공
- 매출·지출 및 월간 자금 흐름 정리
- 카드소비와 유동인구 변화 비교
- 분석 결과 기반 골목상권 회복 플랜 제공
- 금융 체온계를 통한 업종 평균 비교
- 지역·업종·매출 조건 기반 정책·지원사업 추천
- AI 리포트와 우측 AI 비서 채팅
- 좌측 파트너 메뉴 및 우측 AI 비서 패널 접기·펼치기

## 4. 현재 프로토타입 상태

- 메인 화면: 구현 완료
- 화면 데이터: 더미 데이터 기반
- 골목상권 회복 플랜: 근거 수치 기반 운영 행동·참고용 금융 효과 표시
- AI 비서: 외부 AI 연결 없이 더미 답변 사용
- 백엔드 API: 설계 완료, 구현 예정
- 데이터베이스: 스키마 설계 완료, 구현 예정
- 실제 데이터: 원천파일을 저장하지 않고 허용된 집계·분석 결과만 반영 예정

## 5. 화면 실행 방법

현재 메인 화면은 별도 서버 없이 HTML 파일로 확인할 수 있습니다.

1. `prototype/main-screen.html` 파일을 엽니다.
2. Chrome 또는 Edge 브라우저에서 확인합니다.
3. 좌측 파트너 메뉴와 우측 AI 비서 버튼을 눌러 접기·펼치기를 확인합니다.
4. AI 비서 입력창에서 질문을 입력해 더미 답변을 확인합니다.

현재 화면은 정적 프로토타입이므로 데이터베이스나 외부 AI API가 연결되어 있지 않습니다.

## 6. 기술 스택

### 예정 백엔드

- Python
- Django
- Django REST Framework
- MySQL

### 주요 라이브러리

- `mysqlclient`: Django와 MySQL 연결
- `django-filter`: 지역·업종·기간·매출 조건 검색
- `drf-spectacular`: API 문서 자동 생성
- `django-environ`: 환경변수 및 API 키 관리
- `pandas`, `numpy`: 데이터 분석
- `httpx`: 공공데이터 API 호출
- `Pillow`: 이미지 업로드 처리
- `pytest`, `pytest-django`: 테스트
- `ruff`: 코드 검사 및 포맷팅

## 8. 데이터 원칙

- 실제 카드사·통신사 원천데이터 파일은 저장소에 포함하지 않습니다.
- 프로토타입은 AI 생성 더미 데이터로 기능을 검증합니다.
- 발표에는 허용된 집계·분석 결과와 시각화만 사용합니다.
- 상권·업종 데이터 분석은 확정적인 원인이 아닌 원인 후보·영향 요인으로 표시합니다.
- 회복 플랜의 소비 기회 규모와 금융 효과는 비교지표 기반 참고용 시나리오입니다.
- 수치의 기간·지역·업종 기준을 함께 표시합니다.
- 금융 체온계는 참고용 비교 지표이며 실제 금융 심사 결과가 아닙니다.

## 9. 개발 예정 순서

```text
개발환경 구성
    ↓
Django·MySQL 기본 구조 생성
    ↓
더미 데이터와 DB 구축
    ↓
분석·대시보드·리포트 API 구현
    ↓
골목상권 회복 플랜 연결
    ↓
HTML 화면과 API 연결
    ↓
실제 집계·분석 결과 일부 반영
    ↓
테스트 및 발표 시연 점검
    ↓
배포·제출 파일 정리
```
