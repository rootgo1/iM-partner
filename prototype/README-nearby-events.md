# 대구 행사 지도

## 자료와 화면

2026-09-18 사용자가 제공한 `전국문화축제표준데이터.csv`를 읽어 전국 1,305행에서 대구 56행을 추출했습니다. 이름과 시작·종료일이 같은 중복 10행을 병합하여 **46개 행사 기록**을 `data/daegu-festivals.json`에 보관합니다. 원본 CSV는 변경하지 않았습니다.

- 인코딩: EUC-KR/CP949. 데이터 기준일: 2026-05-14~2026-08-14.
- 행사 일정: 2023-04-08~2027-01-03. 과거 행사의 연도를 변경하지 않습니다.
- CSV 등록 행사장 좌표 31개를 지도와 직선거리 계산에 사용합니다.
- 행사장과 다른 시청·구청 등록 지점으로 의심되는 13개, 좌표가 없는 2개는 핀·거리 계산에서 제외합니다. 원본 좌표와 주소, 병합 근거는 JSON에 보존했습니다.
- 기본은 오늘(한국 시간) 기준 진행·예정 행사, 5km 이내, 가까운 순입니다. 해당 범위에 없으면 대구 전체를 먼저 보여줍니다. 오늘 이후 일정 자체가 없으면 전체 기록과 안내를 표시합니다.
- 일정(진행·예정/전체 기록), 거리(3/5/10km/대구 전체)를 변경할 수 있습니다. 좌표 미확인 행사는 대구 전체에서 확인합니다.
- 목록 선택 시 지도가 해당 위치로 이동하고, 접이식 상세에서 장소·설명·연락처·원본 기준일·홈페이지를 확인합니다.
- 현재 기준 위치는 **대구 중구 예시 좌표**이며 실제 소현이네 고기굽는집 주소가 아닙니다. 실제 위치 설정 전까지 예시임을 화면에 표시합니다. 반경은 도보거리가 아닌 직선거리입니다.
- 매출·상권 차트는 계속 생성 자료입니다. 행사와 매출 변화의 인과관계는 추정하지 않습니다.

## 카카오 지도 설정

카카오 지도 SDK와 번호 마커 연결을 구현했습니다. 현재 사용자는 키를 발급하지 않아 `map-config.js`의 `kakaoJavaScriptKey`가 비어 있습니다. 키가 없거나 SDK를 불러오지 못하면 기존 OpenStreetMap으로 선택 행사 위치를 표시합니다. 카카오맵 크게 보기·장소 찾기 링크는 키 없이 사용할 수 있습니다. 카카오 실서비스 연결은 키 발급·도메인 등록 뒤 확인해야 합니다.

1. [Kakao Developers](https://developers.kakao.com/)에서 앱을 만들고 카카오맵 API를 활성화합니다.
2. JavaScript 키의 SDK 도메인에 실제 사용할 주소를 등록합니다. 로컬은 `http://127.0.0.1:8876`이며, localhost를 사용하면 해당 주소도 별도로 등록합니다.
3. `prototype/map-config.js`의 `kakaoJavaScriptKey`에 **브라우저용 JavaScript 키**만 입력합니다. REST API 키·Admin 키는 넣지 않습니다.
4. 페이지를 새로고침하면 카카오 지도와 행사 번호 마커가 표시됩니다. 마커와 행사 목록은 함께 선택됩니다.

2026-09-18 공식 문서 확인: 첫 번째로 카카오맵 API를 활성화한 앱에 무료 쿼터가 적용되며, Web 지도 SDK 일간 무료 제공량은 300,000건입니다. 추가 앱·초과 사용 조건은 공식 문서를 따릅니다. 이 작업에서는 비즈월렛 연결이나 유료 설정을 하지 않았습니다.

- [무료 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota)
- [지도 SDK 설정](https://apis.map.kakao.com/web/guide/)
- [2026-07-21 운영 방식 변경](https://devtalk.kakao.com/t/api-notice-on-new-kakao-map-api-features-and-free-quota-policy/150222)

실제 가게 위치를 확보하면 동일 설정의 `location`에 `{ lat, lng, label, example: false }`를 지정할 수 있습니다. 현재 프로필의 행정구 이름만으로 정확한 가게 좌표를 만들지 않습니다.

## CSV 갱신

프로젝트 루트에서 실행합니다.

```powershell
node server/import-daegu-festivals.cjs "C:/path/to/전국문화축제표준데이터.csv"
node --test prototype/tests/daegu-festivals-import.test.cjs prototype/tests/nearby-events.test.cjs
```

주소 우선 대구 선별, 날짜 검증, 제한적인 이름 표기 정규화, 같은 일정 중복 병합, 행정기관 좌표 제외를 수행합니다. 원본 파일명·SHA256·기준일·원본 행을 정제 JSON에 기록합니다. 여러 장소에서 열리는 행사는 원본에 등록된 한 지점만 표시할 수 있습니다. 새로운 CSV의 장소 정확도는 갱신 때 다시 확인해야 합니다.

별도 행사 API나 관광공사 API는 사용하지 않습니다. `node server/preview-server.cjs` 등 HTTP 정적 서버에서 확인하세요. HTML을 파일로 직접 열면 브라우저 보안 정책으로 JSON을 불러오지 못할 수 있습니다.
