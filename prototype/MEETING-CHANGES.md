## 화면 배치·복수 지표 선택 추가 수정 — 최신 반영

- 섹션의 고정 높이와 내부 세로 스크롤을 제거했습니다. 내용에 맞춰 섹션이 늘어나며 전체 화면에서 스크롤합니다. 모든 섹션이 화면에 맞으면 기존 단위 이동을 유지하고, 긴 섹션이 있으면 연속 스크롤로 바꿔 하단 내용도 접근할 수 있게 했습니다. 진단 카드 안쪽 스크롤도 제거했습니다.
- 체온계 증감은 ‘▼ 8.7° 낮음’처럼 간결하게 표시합니다. 별도 갱신 상태 줄을 삭제하고 자료 기준일·지수 갱신일은 ‘현재 나의 금융지수’의 도움말로 옮겼습니다. 상권 요약 카드의 화살표는 숫자 크기의 약 절반으로 줄이고 ‘생성 자료’ 반복 문구를 삭제했습니다. 비교 기간과 자료 범위는 유지합니다.
- 운영 안내에서 ‘생성 POS 확인 가능 시간’을 삭제했습니다. ‘판매에 맞춰 재료와 응대를 점검하세요.’처럼 행동이 명확한 문장으로 바꾸고 문장 끝에 마침표를 적용했습니다.
- 네 차트 지표를 여러 개 선택해 함께 강조할 수 있습니다. 선택하지 않은 선은 흐리게 표시하고, 선택을 모두 해제하면 전체를 표시합니다. 시간대별·요일별 전환 시 선택을 유지합니다. 네 지표 비교의 가독성을 위해 2시간 구간을 유지합니다.
- ‘현재 매출진단’의 중복 ‘만만 원’을 수정하고, 선택 기간의 해당 2시간 구간 일평균 매출·가게 앞 통행과 하루 매출 중 비중을 표시합니다. 매출과 통행은 각각 실제 관측일 수로 나누며 해석도 같은 선택 기간으로 통일합니다. 좁은 화면에서는 지표를 세로로 배치합니다.
- ‘가게 주변의 오늘’은 과거 관측 패턴에 더 적합한 ‘주변 상권 흐름’으로 변경했습니다.
- 수정 파일: `meeting-data.js`, `meeting-ui.js`, `meeting-preview.css`, `smooth-scroll.js`, `tests/meeting-preview.test.cjs`, `tests/meeting-revisions.browser.test.cjs`, `tests/operating-guidance.test.cjs`, 루트 `README.md`, 이 문서. 신규 검사: `tests/dashboard-layout.browser.test.cjs`.

- 상권 소비 변화·유동인구 변화에 ▲/▼와 상승·하락 색상을 추가했습니다. 비교 기간, 자료 범위, 생성 자료 표기를 각각 나누고 단어 단위 줄바꿈을 적용했습니다.
- 시간대별 운영 안내는 최신 기록일까지의 최근 30일로 계산합니다. 고정 관측 범위 대신 ‘하루 매출 중 비중’을 표시합니다. 관측일이 30일 미만이면 자료 대기 상태로 표시합니다.

## 로그인 화면 추가 수정 — 최신 반영

아래 최초 반영 내용 중 로그인 이미지·안내 배치는 다음 내용으로 대체합니다.

- 좌측 서비스 이미지를 사용하지 않고 매출진단·회복전략·iM비서 소개를 01~03으로 배치했습니다.
- 우측 제목은 ‘아이디 로그인’으로 변경했습니다. 비로그인 상태, 소개 설명, 계정으로 로그인, 인증 연결 안내, 로그아웃 완료 안내를 제거했습니다.
- PC에서는 좌우 약 53:47 비율과 같은 카드 높이를 사용하며, 오른쪽 입력 영역을 세로 가운데에 배치합니다. 좁은 화면에서는 한 열로 전환합니다.
- 아이디·비밀번호 입력창과 로그인 버튼 너비를 통일하고 버튼 높이는 58px, 버튼 문구는 가운데 정렬했습니다.
- 최종 문구에서 ‘매출부터 운영 전략까지’ 뒤 쉼표를 제거했습니다. 작게 보이던 본문·보조 설명 중심으로 글자 크기를 조정했습니다. PC 소개문 15→17px, 기능 제목 16→18px·설명 13→15px, 입력창 14→17px, 로그인 버튼 16→18px입니다. 모바일 기능 설명은 12→14px, 로그인 제목은 27→30px로 확대했습니다.
- 관련 CSS의 사용하지 않는 이미지·데모·상태 안내 스타일을 정리했습니다.
- 로그인 HTML·CSS·JS, 로그인 구조·브라우저 테스트, 공통 브라우저 테스트의 로그인 확인 항목, 로그인 README와 이 문서를 갱신했습니다.
- 1366×768, 1440×900, 2048×1151, 모바일 390×844에서 배치·입력 검사·로그아웃 복귀·JavaScript 비활성 검사를 통과했습니다.

## 변경 내용

0. **스크롤**: 콘텐츠 높이만으로 스크롤을 차단하던 표식을 제거했습니다. 실제 세로 스크롤 가능 여부와 입력 방향의 남은 거리를 확인합니다. 배너·SVG 그래프 위에서도 스크롤되며 내부 스크롤 끝에서는 바깥 섹션으로 이동합니다. 터치·동작 줄이기 설정은 기본 브라우저 스크롤을 사용합니다.
1. **로그인**: 실제 서비스 홈 캡처와 세 가지 기능 소개를 배치했습니다. 데모 링크·배지와 임의 입력 성공 처리를 제거했습니다. 아이디·비밀번호 검사, 비밀번호 보기, 로그아웃 복귀는 유지합니다. 인증 서버가 없으므로 현재 로그인 성공이나 접근 통제를 제공하지 않습니다.
2. **홈**: 배너 제목을 확대했습니다. 금융지수는 최근 1개월을 30일로 정의하고, 매일의 `max(0, min(100, 100 - 지출/매출 × 100))`를 산술평균합니다. 직전의 겹치지 않는 30일과 비교하며 ▲/▼ 및 색상으로 변화를 구분합니다. 한국 시간 기준 날짜 변경과 화면 복귀 시 갱신합니다. 상권 소비는 상권 내 서비스 이용 4개 가게의 POS 합계로 계산하며 외부 카드소비 표본과 분리합니다.
3. **그래프·진단**: ‘요일/시간대별 유동인구와 매출량’ 그래프에 상권 유동인구·카드소비·우리 가게 매출·우리 가게 앞 유동인구를 함께 표시합니다. 색과 실선/점선으로 구분하며 범례·선 클릭 또는 키보드로 강조·해제할 수 있습니다. 단위 차이를 고려해 각 시리즈 최대=100으로 환산하고 원 수치는 점의 툴팁으로 표시합니다. 요일별 값은 관측일 수로 나눈 일평균입니다. ‘현재 매출진단’은 현재 시각이 속한 2시간 구간의 기록과 행동 안내를 표시하고 영업시간 밖 상태도 구분합니다.
4. **CCTV·POS**: 전월 동일 요일·동일 시간대 관측값의 합산 전환율과 비교합니다. 예시는 9/3 목요일과 8/6·13·20·27 목요일입니다. 입장 전환율=입장객/통행인구, 결제 전환율(추정)=유효 매장 결제/입장객으로 계산합니다. 변화는 %p로 표시하며 체류·객단가·판단 수준 보조 카드는 통행인구·입장 전환율·결제 전환율·전월 비교로 교체했습니다. 실행 후 7일 비교는 별도 대기 상태로 유지합니다.
5. **기타**: 운영 안내를 홈 두 번째 섹션으로 이동했습니다. 챗봇 상단 슬라이더를 제거하고 가장자리 드래그와 키보드 너비 조절을 유지했습니다. 매출진단에는 현금보유량·미정산 매출·예정 지출·정산 예정일의 연결 상태를 추가했습니다. 작업 중 추가된 별도 매출진단 컴포넌트도 유지하며 같은 항목을 반영했습니다.

## 데이터·연동 한계

- 현재 거래 자료는 2026-09-02까지의 생성 자료입니다. 금융지수는 최신 자료 기준값과 ‘당일 자료 대기’를 함께 표시합니다. 새로운 자료 없이 현재 날짜의 실거래 수치를 생성하지 않습니다.
- 상권 이용 가게와 매장 앞 유동인구, 전월 CCTV 비교도 기능 확인용 생성 자료이며 실제 외부 연동 결과가 아닙니다.
- 일별 거래가 30일 미만이거나 매출이 0인 날을 포함하는 평균은 미산정 처리합니다. 전환율의 분모가 0이거나 비교 자료가 없으면 비교값을 만들지 않습니다.
- 현금보유량은 잔액 자료가 없어 ‘미연결’입니다. 매출−지출을 현금잔액으로 표시하지 않습니다.
- 실제 인증은 백엔드 연동이 필요합니다. 화면 검토는 루트 `index.html`(로그인), `prototype/main-screen.html`(메인)을 각각 열어 진행합니다.
