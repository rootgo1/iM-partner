# iM파트너 로그인 화면

루트 `index.html`에서 가장 먼저 표시되는 정적 프로토타입 진입 화면입니다.

- 데모 진입 링크와 임의 입력 성공 처리 제거
- `로그인`: 필수 입력 검사와 로그인 실패 메시지 처리
- 왼쪽은 이미지 없이 매출진단·회복전략·iM비서의 핵심 기능을 01~03으로 소개
- 오른쪽은 ‘아이디 로그인’ 제목, 아이디·비밀번호 입력창, 로그인 버튼으로 구성
- 비로그인 상태·중복 제목·인증 연결 안내·로그아웃 완료 문구 제거
- 입력창과 로그인 버튼의 너비를 통일하고 버튼 문구 가운데 정렬
- 글자 크기: PC 소개문 17px, 기능 제목 18px·설명 15px, 입력창 17px, 로그인 버튼 18px. 모바일 기능 설명도 14px 이상으로 표시
- 소개문 ‘매출부터 운영 전략까지’ 뒤 쉼표 제거. 입력창·버튼 높이는 58px로 조정
- 데스크톱: 소개·로그인을 두 열로 배치하고 내용이 길면 페이지 스크롤 허용
- 메인 화면 `로그아웃`: 이 화면으로 돌아오며 메인 문서의 메모리 상태를 종료
- 입력값 저장·외부 전송·실제 인증·접근 통제: 없음
- 실제 iM뱅크 또는 다른 서비스 계정정보 입력: 금지

현재는 **인증 서버 미연결 상태**입니다. 평상시 연결 안내 문구는 표시하지 않고, 로그인 시도 시 실패 메시지를 표시합니다. 메인 UI 검토는 `prototype/main-screen.html`을 직접 실행합니다.

실제 로그인·세션·권한 확인은 백엔드 인증 연동이 필요합니다. 로그인 화면에서 입력값을 저장·전송하거나 인증에 성공한 것처럼 메인 화면으로 이동하지 않습니다.

정적 회귀 검사는 프로젝트 루트에서 다음과 같이 실행합니다.

```powershell
node .\prototype\login-preview\login-preview.test.cjs
```

번들 Playwright 경로를 `NODE_PATH`로 지정하면 `visual-login-preview.test.cjs`에서 데스크톱 소개 항목 잘림, 문구, 모바일, 루트 진입, 로그아웃 복귀, JavaScript 비활성 안전성을 검사할 수 있습니다.
