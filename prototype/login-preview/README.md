# iM파트너 비로그인 시작 화면

루트 `index.html`에서 가장 먼저 표시되는 정적 프로토타입 진입 화면입니다.

- `로그인 없이 데모 시작`: 계정 입력 없이 기존 생성 데이터 화면으로 이동
- `입력 후 데모 시작`: 임의 아이디·비밀번호의 빈 값만 확인한 뒤 선택한 서비스 화면으로 이동
- 왼쪽 서비스 요약: 가게 현황 → 기회 시간대 → 실행·비교 흐름 안내
- 데스크톱: 주요 내용과 시작하기 기능을 세로 스크롤 없이 한 화면에 표시
- 메인 화면 `로그아웃`: 이 화면으로 돌아오며 메인 문서의 메모리 상태를 종료
- 입력값 저장·외부 전송·실제 인증·접근 통제: 없음
- 실제 iM뱅크 또는 다른 서비스 계정정보 입력: 금지

현재 구현은 **공모전 시연용 화면 전환**이며, 실제 로그인·세션·사업장 소유권 확인을 뜻하지 않습니다. 메인 프로토타입의 직접 실행 주소도 시연 편의를 위해 유지합니다.

백엔드의 실제 로그인·세션·권한 확인이 구현되면 `로그인 없이 데모 시작` 진입 경로를 제거하고 인증 성공 사용자만 메인 화면으로 이동하도록 전환합니다.

정적 회귀 검사는 프로젝트 루트에서 다음과 같이 실행합니다.

```powershell
node .\prototype\login-preview\login-preview.test.cjs
```

번들 Playwright 경로를 `NODE_PATH`로 지정하면 `visual-login-preview.test.cjs`에서 데스크톱 한 화면 배치, 문구, 모바일, 루트 진입, 로그아웃 복귀, JavaScript 비활성 안전성을 검사할 수 있습니다.
