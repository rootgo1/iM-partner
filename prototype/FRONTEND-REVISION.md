## 3. 사후관리 월간 비교와 실행 기록

## 4. 실행 방법

별도 앱 빌드나 패키지 설치 과정은 없습니다. 기존 진입 파일은 루트 `index.html`, 로그인은 `prototype/login-preview/index.html`, 본화면은 `prototype/main-screen.html`입니다.

Node.js가 있는 환경에서 프로젝트 루트의 PowerShell을 열고 다음 명령으로 정적 미리보기 서버를 실행합니다.

```powershell
Set-Location -LiteralPath 'C:\Users\rmsgh\Documents\Projects\iM-partner'
$env:PORT = '8876'
node server/preview-server.cjs
```

브라우저에서 [시작 화면](http://127.0.0.1:8876/prototype/login-preview/index.html)을 열고 ‘데모시작’을 누릅니다. [본화면](http://127.0.0.1:8876/prototype/main-screen.html#dashboard)으로 바로 들어갈 수도 있습니다. 서버를 멈출 때는 실행 중인 터미널에서 `Ctrl+C`를 누릅니다. 이 명령은 정적 파일 미리보기이며, 실제 로그인·업무 서버나 배포를 만드는 명령이 아닙니다. `tmp/`의 임시 검사 서버 파일은 실행에 필요하지 않습니다.
