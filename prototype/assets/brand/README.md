공식 홈페이지에서 사용하는 GIF 및 ICO 원본을 내용 변경 없이 로컬에 저장했습니다. 화면 적용본 PNG는 공식 CI 벡터 파일의 가로형 국문 시그니처에서 심볼만 분리해 투명 배경으로 출력했으며, 모양·색상·비율은 변경하지 않았습니다. 현재 공모전 프로토타입의 상단 홈 링크와 좌측 메뉴 심볼에 사용합니다.

CI는 iM뱅크의 상표·브랜드 자산입니다. 외부 공개, 상업적 배포 또는 공모전 범위를 벗어난 사용 전에는 iM뱅크의 최신 CI 지침과 사용 승인을 별도로 확인해야 합니다.
